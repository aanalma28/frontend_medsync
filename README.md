# MedSync - Frontend MVP

## 🚀 Deskripsi Proyek
Projek ini berfokus pada pelayanan dan sinkronisasi data obat dari sisi dokter dan apotek, sehingga pasien mendapat kepastian adanya obat di apotek rumah sakit dan tidak ada kecemasan tidak mendapat obat selagi menunggu.

## ✨ Fitur Utama (Fase MVP)
- **Autentikasi Pengguna:** Pengguna dibagi menjadi 2 role, yaitu Role Dokter dan Role Apoteker.
- **Dashboard Interaktif:** Dari role dokter, dokter bisa reservasi obat sesuai dengan resep dan ketersediaan obat didalam database, dokter juga bisa melihat obat apa saja yang tersedia didalam database agar bisa mencari alternatif obat lain, setelah memilih obat dan nama pasien, dokter bisa cetak struk resep untuk diberikan ke pasien. Dari role apoteker, apoteker bisa menambahkan jenis obat seperti namanya apa, stoknya berapa, dan lain lain, pasien mengambil struk yang sudah dikumpulkan para pasien ke keranjang dan mengambil obat sesuai dengan resep dokter.
- **Integrasi API:** Komunikasi backend dengan Nest.js
- **Desain Responsif:** Antarmuka yang berjalan mulus dan responsive di perangkat manapun.

## 🛠️ Tech Stack
- **Framework:** Svelte
- **Styling:** Tailwind CSS
- **State Management:** Redux
- **HTTP Client:** Fetch API
